# fin-daries-horror-mod

Хоррор-мод для **Minecraft 1.20.1 (Forge)** по мотивам канала Fin Diaries (@findaries8589).

## Что есть в моде

- **Гигантский чёрный треугольник в небе** — изредка пролетает над игроком в облаках со звуком треска и исчезает.
- **Безликий Стив (длинноногий)** — существо по текстуре Стива без лица, вытянутое до 5 блоков в высоту. Появляется в лесу за деревьями, издаёт пещерный звук. Если подойти слишком близко — игрок выкидывается в главное меню; после повторного входа существа рядом уже нет.
- **Измерение wonderland.avi** — портал может возникнуть в верхнем мире. При входе версия в углу экрана становится `minecraft.1.wonderland.0`. Ярко-зелёная трава с холмами, гигантские маки и одуванчики, искажённые старые деревья, гигантские блоки алмаза, булыжника и верстака. Из них построен дом с сундуком, где лежит записка "fun fun fun fun fun fun wonderland is fun place fun fun". Иногда за игрона наблюдает сущность-Наблюдатель (исчезает при приближении, оставляя одуванчик).
- **Деревянный домик в верхнем мире** — портал → длинный деревянный проход → деревянный дом с мебелью и лифтом. В лифте слышны быстрые шаги длинноногого; когда дверь закрывается — игрок попадает в измерение wonderflowers.
- **Измерение wonderflowers** — гигантские маки, прямая тропинка, река, мост из цветных блоков ("дума"), в конце — остров с порталом из разноцветных точек. Если не прыгнуть в портал — появляется danger_12 (гонится за игроком, при касании выкидывает из мира). Прыжок в портал переносит в cage_wonderland.
- **Измерение cage_wonderland** — деревянные стены, супер-высокие деревья, холмы, вода; дырка в стене с белым порталом — выход в верхний мир. За прохождение выдаётся достижение **"Живой" (alive)**.
- **Дополнительные аномалии**: грибы на ногах (внезапно появляются, исчезают, вокруг игрока кольцо из грибов со звуком пещеры); поднимающийся столб со светящимися жёлтыми точками, оставляющий 50-блочный столб булыжника; синий незнакомец (появляется со звуком воды, при приближении заменяет себя водой); НЛО и прочие 3D-объекты, пролетающие в небе.

## Сборка

Мод невозможно скомпилировать в этом песочнице (нет JDK/Maven и доступа к файлам Forge). Подробности — в **BUILD.md**.

## Ресурсы

Текстуры сущностей взяты из изображений,附加ных к запросу (папка `assets/findaries/textures/entity/`).
